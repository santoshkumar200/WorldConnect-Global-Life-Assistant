**WorldConnect** is a professional-grade mobile application developed by **SK PROJECTS**. It is a "Global Life Assistant" designed to provide emergency assistance, health tracking, and disaster management—all in one place.

---

## 📱 About the Project

Whether you are traveling, at home, or facing a crisis, WorldConnect gives you the tools to stay safe. Built with a focus on **Offline-First** functionality, critical features like SOS and First Aid work even without an internet connection.

- **Total Screens:** 28+ (Fully Functional)
- **Architecture:** Clean Code with Provider/Bloc & Hive for Local Storage
- **Target Platforms:** Android & iOS

---

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| 🆘 **One-Tap SOS** | Instantly calls local emergency services and sends GPS location to trusted contacts. |
| 🚑 **Offline First Aid** | Step-by-step illustrated guides for CPR, burns, and fractures (No Internet Required). |
| 🌪️ **Disaster Alerts** | Real-time global alerts for earthquakes, floods, and cyclones with interactive maps. |
| 🩺 **Health Suite** | Log blood pressure, sugar, and weight with visual charts and medicine reminders. |
| 🌐 **Smart Translator** | Instant translation for 100+ languages using Google Neural Machine Translation. |
| 👥 **Community Hub** | A real-time social feed to ask for help or volunteer in local crisis areas. |

---

## 🧱 Technical Architecture

| Layer | Technology Used |
| :--- | :--- |
| **Frontend** | Flutter (Dart) |
| **Backend** | Firebase (Auth, Firestore, Cloud Messaging) |
| **Local DB** | Hive & SharedPreferences (for Offline access) |
| **Mapping** | Google Maps API for Flutter |
| **Charts** | fl_chart & geolocator |
| **Notifications** | Flutter Local Notifications |
